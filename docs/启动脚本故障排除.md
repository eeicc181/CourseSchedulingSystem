# 🔧 启动脚本故障排除指南

## 问题：脚本闪退，无法启动

如果启动脚本一闪而过，什么都没启动，请按以下步骤排查：

---

## 🔍 诊断步骤

### 步骤1：运行调试脚本

我已经为您创建了调试脚本，请运行：

```cmd
start-debug.bat
```

这个脚本会：
- 显示详细的环境检查信息
- 列出当前目录文件
- 检查所有必需的环境
- 不会自动关闭，方便查看错误信息

### 步骤2：检查常见问题

#### ❌ 问题1：未在项目根目录运行

**症状**: 提示"未找到pom.xml"

**解决方案**:
```cmd
# 确保在项目根目录运行
cd d:\AAA_CodeLearning\CourseArrange
start.bat
```

项目根目录应该包含：
- pom.xml
- UI 文件夹
- src 文件夹
- start.bat

#### ❌ 问题2：Java环境未安装

**症状**: 提示"未检测到Java环境"

**解决方案**:
1. 下载安装 JDK 1.8+: https://www.oracle.com/java/technologies/downloads/
2. 配置环境变量 JAVA_HOME
3. 验证安装: `java -version`

#### ❌ 问题3：Maven环境未安装

**症状**: 提示"未检测到Maven环境"

**解决方案**:

**方案A: 安装Maven**
1. 下载 Maven: https://maven.apache.org/download.cgi
2. 配置环境变量 MAVEN_HOME
3. 验证安装: `mvn -version`

**方案B: 使用项目自带的Maven Wrapper**
修改脚本，将 `mvn` 改为 `mvnw` (如果项目有mvnw文件)

#### ❌ 问题4：Node.js环境未安装

**症状**: 提示"未检测到Node.js环境"

**解决方案**:
1. 下载安装 Node.js: https://nodejs.org/
2. 验证安装: `node -v` 和 `npm -v`

#### ❌ 问题5：端口被占用

**症状**: 服务启动失败，提示端口已被占用

**解决方案**:
```cmd
# 查看端口占用
netstat -ano | findstr :8080
netstat -ano | findstr :8081

# 停止占用端口的进程
taskkill /F /PID <进程ID>
```

## 🔧 手动配置数据库

如果后端启动失败，可能是数据库配置问题：

1. **启动MySQL服务**
```cmd
net start mysql
```

2. **创建数据库**
```sql
CREATE DATABASE db_course_arrangement CHARACTER SET utf8mb4;
```

3. **导入数据**
```cmd
mysql -u root -p db_course_arrangement < db_course_arrangement.sql
```

4. **检查配置文件**
编辑 `src/main/resources/application-dev.yml`:
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/db_course_arrangement
    username: root  # 修改为你的用户名
    password: 123456  # 修改为你的密码
```

## 💡 常见错误信息及解决方案

### 错误1: "不是内部或外部命令"

**原因**: 命令未添加到系统PATH

**解决**: 
- Java: 添加 `JAVA_HOME\bin` 到 PATH
- Maven: 添加 `MAVEN_HOME\bin` 到 PATH
- Node.js: 重新安装时选择"添加到PATH"

### 错误2: "Address already in use"

**原因**: 端口被占用

**解决**: 
```cmd
# 停止占用8080端口的进程
netstat -ano | findstr :8080
taskkill /F /PID <PID>
```

### 错误3: "Connection refused"

**原因**: MySQL未启动或配置错误

**解决**:
1. 启动MySQL: `net start mysql`
2. 检查数据库配置
3. 验证数据库连接: `mysql -u root -p`

### 错误4: "npm ERR! code ELIFECYCLE"

**原因**: 前端依赖安装失败或版本冲突

**解决**:
```cmd
cd UI\coursearrange
# 清除缓存
npm cache clean --force
# 删除node_modules
rmdir /s /q node_modules
# 重新安装
npm install
```
