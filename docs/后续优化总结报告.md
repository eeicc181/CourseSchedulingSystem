## 🎯 使用指南

### 1. 异常处理

**在 Service 中抛出异常**:
```java
if (data == null) {
    throw new BusinessException("数据不存在");
}

if (StringUtils.isBlank(param)) {
    throw new ValidationException("参数不能为空");
}

if (token == null) {
    throw new AuthenticationException("请先登录");
}
```

**自动返回**:
```json
{
    "code": 1,
    "message": "数据不存在 (错误ID: a1b2c3d4)",
    "data": null
}
```

### 2. 参数校验

**在请求对象中添加注解**:
```java
@Data
public class CreateRequest {
    @NotBlank(message = "名称不能为空")
    @Size(min = 2, max = 50, message = "名称长度2-50")
    private String name;
    
    @Email(message = "邮箱格式不正确")
    private String email;
}
```

**在 Controller 中启用**:
```java
@PostMapping("/create")
public ServerResponse create(@Valid @RequestBody CreateRequest request) {
    // 参数已自动校验
    return service.create(request);
}
```

### 3. Redis 缓存

**查询缓存**:
```java
@Cacheable(value = "teacher", key = "#id")
public Teacher getById(Integer id) {
    return teacherDao.selectById(id);
}
```

**清除缓存**:
```java
@CacheEvict(value = "teacher", key = "#id")
public void update(Teacher teacher) {
    teacherDao.updateById(teacher);
}
```

## ⚠️ 注意事项

### 1. Redis 安装

**使用缓存功能需要**:
1. 下载并安装 Redis
2. 启动 Redis 服务
3. 验证连接：`redis-cli ping`

**如果没有 Redis**:
- 系统仍可正常运行
- 只是没有缓存功能
- 建议安装以获得最佳性能

### 2. 异常使用

**推荐**:
```java
// ✅ 业务逻辑异常
throw new BusinessException("操作失败");

// ✅ 参数校验异常
throw new ValidationException("参数错误");

// ✅ 认证异常
throw new AuthenticationException("未登录");
```

**不推荐**:
```java
// ❌ 不要用异常控制正常流程
if (user == null) {
    throw new BusinessException("用户不存在");
}
// 应该返回 null 或空结果
```

### 3. 缓存策略

**适合缓存**:
- ✅ 读多写少的数据
- ✅ 计算复杂的数据
- ✅ 不经常变化的数据

**不适合缓存**:
- ❌ 实时性要求高的数据
- ❌ 频繁更新的数据
- ❌ 敏感数据
