## ✅ 已完成工作

### 后端API开发

#### 1. 新增实体类
**文件**: `ClassroomUtilizationVO.java`
- 教室利用率统计响应对象
- 包含完整的教室信息和利用率数据
- 嵌套TimeSlotVO类用于时间段信息

**字段列表**:
```java
- id: 教室ID
- classroomNo: 教室编号
- classroomName: 教室名称
- teachbuildNo: 教学楼编号
- teachBuildName: 教学楼名称
- capacity: 容量
- utilizationRate: 利用率（百分比）
- usedHours: 已使用时长
- availableHours: 空闲时长
- status: 当前状态
- timeSlots: 时间段列表
- equipment: 设备信息
- remark: 备注
```

#### 2. 新增Controller
**文件**: `ClassroomUtilizationController.java`

**API端点**:

##### 2.1 获取所有教室利用率
```
GET /classroom/utilization/all
参数: semester (可选)
返回: List<ClassroomUtilizationVO>
```

**功能**:
- 查询所有教室
- 统计每个教室的课程安排
- 计算利用率（基于35个时段/周）
- 计算使用时长和空闲时长
- 生成时间段使用情况

##### 2.2 按教学楼获取利用率
```
GET /classroom/utilization/building/{teachbuildNo}
参数: 
  - teachbuildNo: 教学楼编号
  - semester: 学期（可选）
返回: List<ClassroomUtilizationVO>
```

**功能**:
- 筛选指定教学楼的教室
- 统计该楼教室的利用情况

##### 2.3 获取统计摘要
```
GET /classroom/utilization/summary
参数: semester (可选)
返回: Map<String, Object>
```

**返回数据**:
```json
{
  "totalClassrooms": 50,
  "availableClassrooms": 30,
  "utilizationRate": 65.5,
  "peakHours": "第3-4节",
  "peakUtilization": 85,
  "totalUsageHours": 1200
}
```

## 📊 数据流程

### 完整数据流
```
1. 前端发起请求
   ↓
2. 后端Controller接收
   ↓
3. 查询数据库
   - tb_classroom (教室表)
   - tb_course_plan (课程计划表)
   - tb_teachbuild_info (教学楼表)
   ↓
4. 数据处理和计算
   - 统计每个教室的课程数
   - 计算利用率 = 已用时段 / 总时段 × 100%
   - 计算时长 = 时段数 × 1.5小时
   ↓
5. 构建响应对象
   ↓
6. 返回JSON数据
   ↓
7. 前端接收并转换
   ↓
8. 更新UI和图表
```

## 💡 利用率计算逻辑

### 计算公式
```
总时段数 = 35 (7天 × 5个时段)
已用时段数 = 该教室的课程计划数量
利用率 = (已用时段数 / 总时段数) × 100%
已用时长 = 已用时段数 × 1.5小时
空闲时长 = (总时段数 - 已用时段数) × 1.5小时
```

### 时段定义
```
第1-2节: 08:00-09:35
第3-4节: 09:50-11:25
第5-6节: 14:00-15:35
第7-8节: 15:50-17:25
第9-10节: 19:00-20:35
```
