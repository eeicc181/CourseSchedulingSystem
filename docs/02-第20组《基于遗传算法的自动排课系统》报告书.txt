基于遗传算法的自动排课系统的设计与实现
摘  要

随着教育信息化的发展，教学管理面临着日益复杂的挑战。传统的手工排课方式由于效率低下、容易出错等问题，已无法满足现代教学管理的需求。特别是当面对大量的课程、教师、教室和学生等复杂因素时，手工排课往往难以找到最优解，导致资源浪费和冲突频发。因此，开发一个能够高效、准确地解决排课问题的系统显得尤为重要。
为了解决上述问题，本研究采用遗传算法技术，开发了一个基于遗传算法的自动排课系统。该系统通过模拟生物进化过程，利用选择、交叉、变异等遗传操作，不断优化排课方案，以找到满足各种约束条件（如教师时间、教室资源、学生班级等）的最优解。系统包含自动排课、课程表查看等功能模块，能够自动完成排课任务，并提供灵活的手动调整选项，方便用户根据实际情况进行微调。
基于遗传算法的自动排课系统带来了显著的好处。首先，它大大提高了排课效率，减少了人工排课所需的时间和人力成本。其次，通过优化算法，系统能够找到更优的排课方案，减少冲突和资源浪费，提高教学资源的利用率。此外，系统还能够根据具体情况动态调整课程安排，增加了排课的灵活性和可行性。最重要的是，这种智能化的排课系统有助于提升教学效率，为教师和学生创造更好的教学和学习环境。因此，基于遗传算法的自动排课系统对于教育机构和学生群体来说具有重要的意义和实际应用价值。
关键词：遗传算法；自动排课系统；教学管理;

Design and Implementation of Automatic Class Scheduling System Based on Genetic Algorithm
Abstract
With the development of education informatization, teaching management is facing increasingly complex challenges. The traditional manual scheduling method can no longer meet the needs of modern teaching management due to inefficiency, error-prone and other problems. Especially when facing a large number of courses, teachers, classrooms and students and other complex factors, it is often difficult to find the optimal solution for manual scheduling, which leads to waste of resources and frequent conflicts. Therefore, it is particularly important to develop a system that can efficiently and accurately solve the problem of class scheduling.
In order to solve the above problems, this study developed an automatic class scheduling system based on genetic algorithm technology. The system continuously optimizes the scheduling scheme by simulating the biological evolution process and using genetic operations such as selection, crossover, and mutation to find the optimal solution that satisfies various constraints (e.g., teacher's time, classroom resources, student classes, etc.). The system contains functional modules such as automatic scheduling and schedule viewing, which can automatically complete the scheduling task and provide flexible manual adjustment options to facilitate users to fine-tune according to the actual situation.
The automatic class scheduling system based on genetic algorithm brings significant benefits. First, it greatly improves the efficiency of class scheduling and reduces the time and labor costs required for manual scheduling. Secondly, through the optimization algorithm, the system is able to find better scheduling solutions, reduce conflicts and resource wastage, and improve the utilization of teaching resources. In addition, the system is able to dynamically adjust the course schedule according to the specific situation, increasing the flexibility and feasibility of scheduling. Most importantly, this intelligent scheduling system helps to improve teaching efficiency and create a better teaching and learning environment for teachers and students. Therefore, the automatic class scheduling system based on genetic algorithm is of great significance and practical application value for educational institutions and student groups.
Keywords: genetic algorithm; automated scheduling system; instructional management;

第1章 绪论
1.1 项目背景和意义
项目背景：智能化的校园排课系统是基于WEB的校园教务信息综合管理系统的一项重要功能，能很好的解决上述问题。为响应我国的教育改革和素质教育的号召，学生自主选课及校园内日常标准化选课的信息量日夜增长，合理安排课程的工作量与复杂程度也随之增大，手工管理的传统模式已经无法满足管理者们的需求了。而智能化校园排课系统，能较好地满足了校园教务管理者对选课、排课管理的需求，大大地提高了教学管理的效率[1]。
项目意义：排课问题通常涉及多个约束条件和变量，如教师的时间限制、教室的容量、课程的关联等。遗传算法适用于处理这种多约束条件下的优化问题，能够在复杂的情况下找到较优解。基于遗传算法的自动排课系统体现了智能化技术在教育管理中的应用，有助于提升教育管理的效率和水平，推动智能教育的发展。
1.2 国内外研究现状
国外研究方面，1963 年，C. C. Gotlieb 在其《The Construction of Class-Teacher Time-Tables》[2]一文中首次提出了课表编排的数学模型。1975 年，Even. S 证明了排课问题是一个 NP 完全问题，即无法用计算机实现“穷举法”之外的算法找出最佳解。此后，众多研究者开始考虑用其他方法来解决这一问题，如使用组合逻辑、禁忌搜索、决策系统、贪心算法、图论、模拟退火算法、遗传算法、免疫网络等。其中，遗传算法因具有良好的智能性、并行性、简单易用、鲁棒性强等特点，成为一种优秀的亚启发式算法，并成功应用于例如 TSP、地图着色、卫星轨道控制等方面，在解决课程表问题上也有不错的表现。
国内研究相对国外起步较晚，20 世纪 80 年代以来，清华大学、大连理工大学、原南京工学院、西安交通大学等国内高校都进行了相关的研究并研制了相应的软件。例如清华大学的 TISER 系统、西安科技大学自行开发的排课系统[3]、中山大学基于智能规划的排课系统、华中科技大学的排课系统[4]等。
随着学校扩招，学生和课程数量增加，教室资源紧张，排课问题的复杂性日益凸显。基于遗传算法的自动排课系统通过模拟自然界生物进化过程求解极值，能够在一定程度上较好地解决排课中的多目标调度问题，生成满足各种约束条件的课表。不过，不同学校的具体情况和需求可能有所差异，仍需对算法进行优化和调整，以更好地适应实际应用场景。同时，也有研究者在不断探索将其他算法或技术与遗传算法相结合，以进一步提高排课系统的性能和效果。

第4章 系统实现
4.1用户登录模块
功能模块简介：
在本系统中，用户登录模块包括三部分，身份验证，用户类型和令牌生成（如图4-1）。对于身份验证：前端接收用户输入的用户名，密码和用户类型，与存储在数据库中的用户信息进行比对，验证通过即登录成功，否则提示用户名或密码错误（如图4-2）。身份验证：包括管理员、老师和学生三种角色。不同角色将拥有不同的系统权限和界面展示。令牌生成：验证成功后，后端系统将为用户生成一个唯一的令牌（Token），作为用户后续与系统交互的身份凭证。

核心程序：
@PostMapping("/login")
public ServerResponse adminLogin(@RequestBody UserLoginRequest adminLoginRequest) {
    Map<String, Object> map = new HashMap();
    Admin admin = adminService.adminLogin(adminLoginRequest.getUsername(), adminLoginRequest.getPassword());
    if (admin != null){
        String token = tokenService.getToken(admin);
        map.put("admin", admin);
        map.put("token", token);
        return ServerResponse.ofSuccess(map);
    }
    return ServerResponse.ofError("用户名或密码错误!");
}

功能模块简介：
排课计划系统简洁易用，核心功能包括查询，添加课程任务和排课。用户可以迅速按学期和页码查询课程任务，轻松浏览管理。同时，系统支持手动添加课程计划，并自动设置为有效状态，确保任务即时生效。无论是快速检索还是新增任务，系统都为用户提供了高效便捷的管理体验，让排课工作更加灵活高效。排课计划运用遗传算法，实现自动化排课，确保教学资源高效利用。通过这个系统，学校能够更轻松地规划和管理课程，优化教学资源分配，提升整体教学管理效率。

核心程序：
@Transactional
@Override
public ServerResponse classScheduling(String semester) {
    try {
        log.info("开始排课,时间：" + System.currentTimeMillis());
        long start = System.currentTimeMillis();
        // 1、根据学期获得开课任务
        QueryWrapper<ClassTask> wrapper = new QueryWrapper<ClassTask>().eq("semester", semester);
        List<ClassTask> classTaskList = classTaskDao.selectList(wrapper);
        // 判断是否有开课任务
        if (CollectionUtils.isEmpty(classTaskList)) {
            return ServerResponse.ofError("排课失败，查询不到排课任务！");
        }
        // 2、将开课任务的各项信息进行编码成染色体，分为固定时间与不固定时间
        List<Map<String, List<String>>> geneList = coding(classTaskList);
        // 3、给初始基因编码随机分配时间，得到同班上课时间不冲突的编码
        List<String> resultGeneList = codingTime(geneList);
        // 4、将分配好时间的基因编码以班级分类成为以班级的个体，得到班级的不冲突时间初始编码
        Map<String, List<String>> individualMap = transformIndividual(resultGeneList);
        // 5、遗传进化
        individualMap = geneticEvolution(individualMap);
        // 6、分配教室并做教室冲突检测
        List<String> resultList = finalResult(individualMap);
        // 7、解码最终的染色体获取其中的基因信息
        List<CoursePlan> coursePlanList = decoding(resultList);
        // 8、写入tb_course_plan上课计划表
        coursePlanDao.deleteAllPlan(); // 先删除原来的课程计划
        for (CoursePlan coursePlan : coursePlanList) {
            coursePlanDao.insertCoursePlan(coursePlan.getGradeNo(), coursePlan.getClassNo(), coursePlan.getCourseNo(),
                    coursePlan.getTeacherNo(), coursePlan.getClassroomNo(), coursePlan.getClassTime(), semester);
        }
        log.info("完成排课,耗时：" + (System.currentTimeMillis() - start));
        return ServerResponse.ofSuccess("排课成功！");
    } catch (Exception e) {
        log.error("the error message is:" + "    " + e.getMessage());
        e.printStackTrace();
        return ServerResponse.ofError("排课失败，出现异常!");
    }
}

@GetMapping("/empty/{teachbuildno}")
public ServerResponse getEmptyClassroom(@PathVariable("teachbuildno") String teachbuildNo) {
    // 首先查询该教学楼下面的所有教室
    QueryWrapper<Classroom> wrapper1 = new QueryWrapper();
    wrapper1.eq("teachbuild_no", teachbuildNo);
    // 指定教学楼下的所有教室
    List<Classroom> allClassroom = classroomService.list(wrapper1);
    List<CoursePlan> coursePlanList = coursePlanService.list();
    // 得到已经使用了的教室编号
    Set<String> usedClaassroom = new HashSet<>();
    for (int i = 0; i < coursePlanList.size(); i++) {
        // 截取占用的教室所属编号前两位，即教学楼编号
        if (teachbuildNo.equals(coursePlanList.get(i).getClassroomNo().substring(0, 2))) {
            usedClaassroom.add(coursePlanList.get(i).getClassroomNo());
        }
    }
    QueryWrapper<Classroom> wrapper2 = new QueryWrapper();
    wrapper2.in("classroom_no", usedClaassroom);
    wrapper2.orderByAsc("classroom_no");
    List<Classroom> used = classroomService.list(wrapper2);
    // 取差
    Set<Classroom> newList = getSub(allClassroom, used);
    return ServerResponse.ofSuccess(newList);
}
