# 🚀 一键启动脚本使用说明

## 📋 脚本文件说明

本项目提供了一键启动和停止脚本，支持 Windows 和 Linux/Mac 系统。

### Windows 系统
- **start.bat** - 一键启动脚本
- **stop.bat** - 一键停止脚本

### Linux/Mac 系统
- **start.sh** - 一键启动脚本
- **stop.sh** - 一键停止脚本

---

## ⚙️ 环境要求

在使用一键启动脚本前，请确保已安装以下环境：

### 必需环境
1. **JDK 1.8+**
   - 检查命令: `java -version`
   - 下载地址: https://www.oracle.com/java/technologies/downloads/

2. **Node.js 6.0+**
   - 检查命令: `node -v`
   - 下载地址: https://nodejs.org/

3. **Maven 3.0+**
   - 检查命令: `mvn -v`
   - 下载地址: https://maven.apache.org/download.cgi

4. **MySQL 8.0+**
   - 确保MySQL服务已启动
   - 已导入数据库脚本 `db_course_arrangement.sql`

## 🎯 Windows 使用方法

### 启动服务

#### 方法一：双击运行
1. 双击 `start.bat` 文件
2. 等待脚本自动检查环境并启动服务
3. 浏览器会自动打开 http://localhost:8081

2. 脚本会自动停止所有服务

```cmd
cd d:\AAA_CodeLearning\CourseArrange
```

- 关闭启动时弹出的两个命令行窗口

## 🐧 Linux/Mac 使用方法

### 首次使用：添加执行权限
```bash
cd /path/to/CourseArrange
chmod +x start.sh stop.sh
```

### 启动服务
```bash
./start.sh
```

### 停止服务
```bash

```

### 查看日志
```bash

# 查看前端日志
tail -f logs/frontend.log
```

## 📝 启动流程说明

### 启动脚本执行流程

1. **环境检查** (约5秒)
   - 检查 Java 环境
   - 检查 Node.js 环境
   - 检查 npm 环境

2. **启动后端** (约30秒)
   - 使用 Maven 启动 Spring Boot 应用
   - 后端服务运行在 http://localhost:8080
   - 等待后端完全启动

3. **启动前端** (约10秒)
   - 首次运行会自动安装依赖 (需要更长时间)
   - 启动 Vue 开发服务器
   - 前端服务运行在 http://localhost:8081

4. **自动打开浏览器**
   - 自动打开前端页面
   - 可以开始使用系统

### 总耗时
- **首次启动**: 约 3-5 分钟 (包含依赖安装)
- **后续启动**: 约 40-50 秒

## ❗ 常见问题

### 1. 端口被占用

**问题**: 提示端口 8080 或 8081 已被占用

**解决方案**:
```cmd
# Windows - 查看端口占用
netstat -ano | findstr :8080
netstat -ano | findstr :8081

# 停止占用端口的进程
taskkill /F /PID <进程ID>

# Linux/Mac - 查看端口占用
lsof -i :8080
lsof -i :8081

# 停止占用端口的进程
kill -9 <进程ID>
```

### 2. 数据库连接失败

**问题**: 后端启动失败，提示数据库连接错误

**解决方案**:
1. 确认 MySQL 服务已启动
2. 检查数据库配置文件 `src/main/resources/application-dev.yml`
3. 确认数据库名称、用户名、密码是否正确
4. 确认已导入数据库脚本

### 3. 前端依赖安装失败

**问题**: npm install 失败或速度很慢

**解决方案**:
```cmd
# 使用淘宝镜像
npm config set registry https://registry.npmmirror.com

# 清除缓存后重试
npm cache clean --force
cd UI/coursearrange
npm install
```

### 4. Maven 下载依赖慢

**问题**: Maven 下载依赖速度很慢

**解决方案**:
- 项目已配置阿里云 Maven 镜像
- 如仍然很慢，检查网络连接
- 或手动配置 Maven settings.xml

### 5. 脚本执行权限问题 (Linux/Mac)

**问题**: Permission denied

**解决方案**:
```bash
chmod +x start.sh stop.sh
```

## 🔧 高级配置

### 修改端口

#### 后端端口 (默认 8080)
修改文件: `src/main/resources/application.yml`
```yaml
server:
  port: 8080  # 修改为其他端口
```

#### 前端端口 (默认 8081)
修改文件: `UI/coursearrange/config/index.js`
```javascript
dev: {
  port: 8081,  // 修改为其他端口
}
```

### 修改数据库配置
修改文件: `src/main/resources/application-dev.yml`
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/db_course_arrangement
    username: root
    password: your_password
```

## 🛑 停止服务

### 正常停止
使用提供的停止脚本：
- Windows: 运行 `stop.bat`
- Linux/Mac: 运行 `./stop.sh`

### 强制停止
如果正常停止失败，可以手动停止：

**Windows:**
```cmd
# 停止所有Java进程
taskkill /F /IM java.exe

# 停止所有Node进程
taskkill /F /IM node.exe
```

**Linux/Mac:**
```bash
# 停止所有Java进程
pkill -9 java

# 停止所有Node进程
pkill -9 node
```

## 💡 使用建议

1. **首次启动**
   - 首次启动会安装前端依赖，需要较长时间
   - 建议在网络良好的环境下进行
   - 可以先手动安装依赖: `cd UI/coursearrange && npm install`

2. **开发调试**
   - 使用一键启动脚本适合快速启动和演示
   - 开发时建议分别启动后端和前端，便于调试
   - 后端: `mvn spring-boot:run`
   - 前端: `cd UI/coursearrange && npm run dev`

3. **生产部署**
   - 一键启动脚本仅用于开发环境
   - 生产环境请使用专业的部署方案
   - 建议使用 Docker 或 Nginx + Tomcat
