# 🚀 第二阶段开发 - 教室利用率分析

## 📋 开发计划

### 阶段目标
创建教室利用率分析页面，提供全面的教室使用情况统计和可视化分析。

### 核心功能

#### 1. 统计卡片（4个）
- 📊 教室总数 + 可用教室数
- 📈 平均利用率 + 趋势指示
- ⏰ 高峰时段 + 峰值利用率
- 🕐 总使用时长统计

#### 2. 可视化图表（4个）
- 📊 **利用率柱状图/折线图** - 按教学楼统计
- 🥧 **状态饼图** - 空闲/使用中/维护中
- 🔥 **时段热力图** - 周×时段使用情况
- 📈 **周趋势图** - 每周使用趋势

#### 3. 教室列表
- 📋 详细信息表格
- 🔍 搜索和筛选
- 📊 利用率进度条
- ⏰ 时间轴展示
- 👁️ 详情查看
- 📅 课表查看

#### 4. 筛选工具
- 🗓️ 学期选择
- 🏢 教学楼筛选
- ⏰ 时间段筛选

---

## 💻 技术实现

### 数据来源
1. **教室数据**: `/classroom/findAll`
2. **课程计划**: `/coursePlan/findBySemester/{semester}`
3. **教学楼**: `/teachbuild/findAll`
4. **学期列表**: `/semester`

### 利用率计算
```javascript
利用率 = (已使用时段数 / 总时段数) × 100%
总时段数 = 7天 × 5个时段 = 35
```

### 图表库
- ECharts 5.x
- 柱状图、折线图、饼图、热力图

## 🎨 设计规范

### 颜色方案
- 空闲: #67C23A (绿色)
- 使用中: #E6A23C (橙色)
- 维护中: #F56C6C (红色)
- 主色: #667eea (紫色)

### 利用率等级
- 0-30%: 低利用 (绿色)
- 31-60%: 中等 (蓝色)
- 61-80%: 良好 (橙色)
- 81-100%: 高利用 (红色)
