### 三、设计规范统一 🎯

#### 配色方案
- **主色调**: 紫色渐变 (#667eea → #764ba2)
- **辅助色**: 深色侧边栏 (#2c3e50, #34495e)
- **背景色**: 浅灰 (#f5f7fa)
- **文字色**: 深灰 (#333), 白色 (#fff)

#### 组件规范
- **圆角**: 8px (输入框), 12px (卡片), 20px (按钮)
- **阴影**: 0 2px 12px rgba(0,0,0,0.08)
- **过渡**: all 0.3s ease
- **间距**: 10px, 20px (标准间距)

#### 交互规范
- 按钮悬停: 向上移动 2px + 阴影增强
- 卡片悬停: 向上移动 2px + 阴影增强
- 输入框焦点: 边框颜色变化 + 外发光效果
- 菜单项: 背景色渐变 + 平滑过渡
