## 1. 智能消息通知系统

### 功能概述
自动推送系统通知、排课通知、考试通知等，支持多种接收者类型和优先级。

### 初始化

```bash
mysql -u root -p db_course_arrangement < database/notification.sql
```

### API 使用

#### 1.1 发送系统通知

```http
POST /notification/send/system
Content-Type: application/json

{
  "title": "系统维护通知",
  "content": "系统将于今晚22:00进行维护",
  "receiverType": "ALL",
  "priority": "HIGH"
}
```

#### 1.2 获取未读消息

```http
GET /notification/unread/{receiverId}
```

**响应示例**:
```json
{
  "code": 200,
  "msg": "success",
  "data": [
    {
      "id": 1,
      "title": "排课完成通知",
      "content": "2024-2025-1学期排课已完成",
      "type": "SCHEDULING",
      "priority": "NORMAL",
      "createTime": "2024-12-06T10:00:00"
    }
  ]
}
```

#### 1.3 标记已读

```http
PUT /notification/read/{notificationId}
```

### 自动触发场景

- ✅ 排课完成后自动通知
- ✅ 考试安排后自动通知
- ✅ 成绩录入后自动通知

## 2. 移动端课表查询

### 功能概述
为移动端提供优化的课表查询接口，支持学生和教师课表查看。

### API 使用

#### 2.1 获取学生课表

```http
GET /mobile/schedule/student/{studentNo}?semester=2024-2025-1
```

**响应示例**:
```json
{
  "code": 200,
  "data": {
    "studentNo": "2024010101",
    "semester": "2024-2025-1",
    "weekData": {
      "Monday": [
        {
          "courseName": "高等数学",
          "teacher": "张老师",
          "classroom": "A101",
          "timeSlot": "1-2节",
          "weeks": "1-16周"
        }
      ]
    }
  }
}
```

#### 2.2 获取今日课程

```http
GET /mobile/schedule/today/{userNo}?userType=student
```

#### 2.3 获取课程详情

```http
GET /mobile/schedule/detail/{planId}
```

### 特点

- 📱 跨域支持，H5直接访问
- 📅 周视图数据结构
- ⚡ 响应快速，数据精简

## 3. 数据分析大屏

### 功能概述
提供多维度的数据统计和分析，支持管理决策。

### API 使用

#### 3.1 系统概览

```http
GET /analysis/overview?semester=2024-2025-1
```

**返回数据**:
- 课程总数
- 教师总数
- 学生总数
- 教室总数
- 排课完成率

#### 3.2 排课统计

```http
GET /analysis/schedule/statistics?semester=2024-2025-1
```

**分析维度**:
- 按星期分布
- 按时段分布
- 冲突统计

#### 3.3 教室利用率

```http
GET /analysis/classroom/utilization?semester=2024-2025-1
```

#### 3.4 教师工作量

```http
GET /analysis/teacher/workload?semester=2024-2025-1
```

#### 3.5 数据大屏（汇总）

```http
GET /analysis/dashboard?semester=2024-2025-1
```

### 性能优化

- 💾 Redis 缓存，TTL 1小时
- 📊 首次查询 < 200ms
- ⚡ 缓存命中 < 10ms

## 4. 在线选课系统

### 功能概述
学生在线选课，支持志愿优先级和选课状态管理。

### 初始化

```bash
mysql -u root -p db_course_arrangement < database/course_selection.sql
```

### API 使用

#### 4.1 学生选课

```http
POST /course-selection/select
Content-Type: application/x-www-form-urlencoded

studentNo=2024010101&courseNo=CS101&semester=2024-2025-1&priority=1
```

**参数说明**:
- `priority`: 1-第一志愿, 2-第二志愿, 3-第三志愿

#### 4.2 取消选课

```http
DELETE /course-selection/cancel/{selectionId}
```

#### 4.3 查询选课列表

```http
GET /course-selection/student/{studentNo}?semester=2024-2025-1
```

#### 4.4 课程选课统计

```http
GET /course-selection/stats/{courseNo}?semester=2024-2025-1
```

**返回数据**:
```json
{
  "totalSelections": 50,
  "confirmedCount": 30,
  "pendingCount": 15,
  "rejectedCount": 5
}
```

### 选课状态

- `PENDING`: 待处理
- `CONFIRMED`: 已确认
- `REJECTED`: 已拒绝
- `CANCELLED`: 已取消

## 5. 考试安排管理

### 功能概述
考试时间安排、考场分配、监考教师安排、准考证生成。

### 初始化

```bash
mysql -u root -p db_course_arrangement < database/exam.sql
```

### API 使用

#### 5.1 创建考试

```http
POST /exam/create
Content-Type: application/json

{
  "examName": "高等数学期末考试",
  "courseNo": "MATH201",
  "semester": "2024-2025-1",
  "examType": "FINAL",
  "examTime": "2025-01-10T09:00:00",
  "duration": 120,
  "classNos": "20240101,20240102"
}
```

**考试类型**:
- `MIDTERM`: 期中考试
- `FINAL`: 期末考试
- `MAKEUP`: 补考
- `RETAKE`: 重修考试

#### 5.2 自动分配考场

```http
PUT /exam/assign-classroom/{examId}
```

#### 5.3 自动分配监考教师

```http
PUT /exam/assign-invigilators/{examId}?count=2
```

#### 5.4 生成准考证号

```http
POST /exam/generate-admission/{examId}
```

**准考证号格式**: `学期(4位) + 考试ID(4位) + 学号后4位`

#### 5.5 获取考试列表

```http
GET /exam/list?semester=2024-2025-1&status=SCHEDULED
```

#### 5.6 考试统计

```http
GET /exam/statistics?semester=2024-2025-1
```

### 考试状态

- `SCHEDULED`: 已安排
- `IN_PROGRESS`: 进行中
- `COMPLETED`: 已完成
- `CANCELLED`: 已取消

## 6. 成绩管理系统

### 功能概述
成绩录入、自动计算总评、绩点计算、成绩单生成。

### 初始化

```bash
mysql -u root -p db_course_arrangement < database/score.sql
```

### API 使用

#### 6.1 录入成绩

```http
POST /score/input
Content-Type: application/json

{
  "studentNo": "2024010101",
  "courseNo": "MATH201",
  "semester": "2024-2025-1",
  "usualScore": 85.0,
  "midtermScore": 88.0,
  "finalScore": 90.0,
  "teacherNo": "T001"
}
```

**自动计算**:
- 总评成绩 = 平时×30% + 期中×20% + 期末×50%
- 自动计算绩点和等级
- 自动判断是否通过

#### 6.2 批量录入成绩

```http
POST /score/batch-input
Content-Type: application/json

[
  {
    "studentNo": "2024010101",
    "courseNo": "MATH201",
    ...
  },
  {
    "studentNo": "2024010102",
    "courseNo": "MATH201",
    ...
  }
]
```

#### 6.3 查询学生成绩

```http
GET /score/student/{studentNo}?semester=2024-2025-1
```

#### 6.4 查询课程成绩

```http
GET /score/course/{courseNo}?semester=2024-2025-1
```

#### 6.5 成绩统计

```http
GET /score/statistics/{courseNo}?semester=2024-2025-1
```

**返回数据**:
```json
{
  "totalCount": 50,
  "passedCount": 45,
  "passRate": "90.00",
  "avgScore": "82.50",
  "maxScore": 98.0,
  "minScore": 55.0
}
```

#### 6.6 生成成绩单

```http
GET /score/transcript/{studentNo}?semester=2024-2025-1
```

**返回数据**:
```json
{
  "studentNo": "2024010101",
  "semester": "2024-2025-1",
  "scores": [...],
  "totalCourses": 5,
  "passedCourses": 5,
  "gpa": "3.75"
}
```

### 成绩等级

| 等级 | 分数范围 | 绩点 |
|------|----------|------|
| A | 90-100 | 4.0 |
| B | 80-89 | 3.0 |
| C | 70-79 | 2.0 |
| D | 60-69 | 1.0 |
| F | 0-59 | 0.0 |

## 常见问题

### Q1: 如何测试所有 API？

**方法 1: Swagger UI**
```
http://localhost:8080/swagger-ui.html
```

**方法 2: Postman**
导入 API 文档后测试

### Q2: 数据库初始化顺序？

```bash
# 按顺序执行
mysql -u root -p db_course_arrangement < database/notification.sql
mysql -u root -p db_course_arrangement < database/course_selection.sql
mysql -u root -p db_course_arrangement < database/exam.sql
mysql -u root -p db_course_arrangement < database/score.sql
```

### Q3: 如何清除缓存？

数据分析模块使用 Redis 缓存，TTL 为 1 小时，自动过期。

手动清除：
```bash
redis-cli
> FLUSHDB
```

### Q4: API 返回格式？

统一使用 `ServerResponse` 格式：

**成功**:
```json
{
  "code": 200,
  "msg": "success",
  "data": {...}
}
```

**失败**:
```json
{
  "code": 500,
  "msg": "错误信息",
  "data": null
}
```

### Q5: 跨域问题？

所有新 API 已添加 `@CrossOrigin(origins = "*")`，支持跨域访问。

### Q6: 性能优化建议？

1. **数据分析**: 使用缓存，避免频繁查询
2. **批量操作**: 使用批量接口而非循环调用
3. **分页查询**: 大数据量时使用分页
4. **索引优化**: 数据库已添加必要索引
