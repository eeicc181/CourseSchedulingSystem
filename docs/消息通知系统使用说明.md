## 📋 功能概述

消息通知系统提供了完整的站内消息功能，支持系统通知、排课通知、变更通知等多种类型的消息推送。

### 核心功能

- ✅ **多类型通知** - 系统/排课/变更/考试/公告
- ✅ **灵活接收者** - 全员/教师/学生/指定用户
- ✅ **优先级管理** - 低/中/高/紧急
- ✅ **异步发送** - 不阻塞主流程
- ✅ **已读未读** - 消息状态管理
- ✅ **统计分析** - 消息数量统计

## 🗄️ 数据库表结构

### tb_notification 表

```sql
CREATE TABLE `tb_notification` (
  `id` INT(11) NOT NULL AUTO_INCREMENT,
  `title` VARCHAR(200) NOT NULL COMMENT '消息标题',
  `content` TEXT NOT NULL COMMENT '消息内容',
  `type` VARCHAR(20) NOT NULL COMMENT '消息类型',
  `receiver_type` VARCHAR(20) NOT NULL COMMENT '接收者类型',
  `receiver_id` VARCHAR(50) DEFAULT NULL COMMENT '接收者ID',
  `priority` VARCHAR(20) NOT NULL COMMENT '优先级',
  `is_read` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否已读',
  `channel` VARCHAR(20) NOT NULL COMMENT '发送渠道',
  `status` VARCHAR(20) NOT NULL COMMENT '发送状态',
  `related_id` VARCHAR(50) DEFAULT NULL COMMENT '关联数据ID',
  `related_type` VARCHAR(50) DEFAULT NULL COMMENT '关联数据类型',
  `create_time` DATETIME NOT NULL,
  `send_time` DATETIME DEFAULT NULL,
  `read_time` DATETIME DEFAULT NULL,
  `deleted` TINYINT(1) NOT NULL DEFAULT 0,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 🔧 API 接口说明

### 1. 获取未读消息列表

**接口**: `GET /notification/unread/{receiverId}`

**参数**:
- `receiverId` - 接收者ID（教师编号或学生编号）

**返回示例**:
```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "id": 1,
      "title": "排课完成通知",
      "content": "2024-2025学年第一学期的课程安排已完成",
      "type": "SCHEDULE",
      "priority": "HIGH",
      "isRead": 0,
      "createTime": "2024-12-06 14:00:00"
    }
  ]
}
```

### 2. 获取消息列表（分页）

**接口**: `GET /notification/list/{receiverId}?page=1&limit=10`

**参数**:
- `receiverId` - 接收者ID
- `page` - 页码（默认1）
- `limit` - 每页数量（默认10）

### 3. 获取未读消息数量

**接口**: `GET /notification/unread/count/{receiverId}`

**返回示例**:
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "count": 5
  }
}
```

### 4. 标记消息为已读

**接口**: `PUT /notification/read/{notificationId}`

**参数**:
- `notificationId` - 消息ID

### 5. 批量标记为已读

**接口**: `PUT /notification/read/all/{receiverId}`

**参数**:
- `receiverId` - 接收者ID

### 6. 删除消息

**接口**: `DELETE /notification/delete/{notificationId}`

**参数**:
- `notificationId` - 消息ID

### 7. 发送系统通知（管理员）

**接口**: `POST /notification/send/system`

**参数**:
- `title` - 标题
- `content` - 内容
- `receiverType` - 接收者类型（ALL/TEACHER/STUDENT/USER）
- `receiverId` - 接收者ID（可选）

**示例**:
```bash
curl -X POST "http://localhost:8080/notification/send/system" \
  -d "title=系统维护通知" \
  -d "content=系统将于今晚22:00进行维护" \
  -d "receiverType=ALL"
```

### 8. 获取消息详情

**接口**: `GET /notification/detail/{notificationId}`

**说明**: 获取详情时会自动标记为已读

### 9. 获取消息统计

**接口**: `GET /notification/stats/{receiverId}`

**返回示例**:
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "unreadCount": 5,
    "totalCount": 20,
    "systemCount": 8,
    "scheduleCount": 12
  }
}
```

## 💻 代码使用示例

### 1. 发送系统通知

```java
@Autowired
private NotificationService notificationService;

// 发送全员通知
notificationService.sendSystemNotification(
    "系统维护通知",
    "系统将于今晚22:00-24:00进行维护",
    NotificationConstants.ReceiverType.ALL,
    null
);

// 发送给指定用户
notificationService.sendSystemNotification(
    "账号审核通过",
    "您的教师账号已审核通过",
    NotificationConstants.ReceiverType.USER,
    "T001"
);
```

### 2. 发送排课完成通知

```java
// 排课完成后自动发送
notificationService.sendScheduleCompleteNotification("2024-2025-1");
```

### 3. 发送课表变更通知

```java
notificationService.sendScheduleChangeNotification(
    "T001",
    "您的周三第3-4节课程教室由101变更为201"
);
```

### 4. 查询未读消息

```java
// 获取未读消息列表
List<Notification> unreadList = notificationService.getUnreadNotifications("T001");

// 获取未读数量
int unreadCount = notificationService.getUnreadCount("T001");
```

### 5. 标记已读

```java
// 标记单个消息为已读
notificationService.markAsRead(1);

// 标记全部为已读
notificationService.markAllAsRead("T001");
```

## 🎯 消息类型说明

### 消息类型（type）

| 类型 | 常量 | 说明 | 使用场景 |
|------|------|------|---------|
| **系统通知** | SYSTEM | 系统级通知 | 系统维护、功能更新 |
| **排课通知** | SCHEDULE | 排课相关 | 排课完成、排课失败 |
| **变更通知** | CHANGE | 课表变更 | 教室变更、时间调整 |
| **考试通知** | EXAM | 考试相关 | 考试安排、成绩发布 |
| **公告通知** | ANNOUNCEMENT | 公告信息 | 重要公告、通知 |

### 接收者类型（receiverType）

| 类型 | 常量 | 说明 |
|------|------|------|
| **全部用户** | ALL | 所有用户都能看到 |
| **教师** | TEACHER | 仅教师可见 |
| **学生** | STUDENT | 仅学生可见 |
| **指定用户** | USER | 指定用户ID |

### 优先级（priority）

| 优先级 | 常量 | 说明 | 显示效果 |
|--------|------|------|---------|
| **低** | LOW | 普通消息 | 灰色 |
| **中** | MEDIUM | 一般重要 | 蓝色 |
| **高** | HIGH | 重要消息 | 橙色 |
| **紧急** | URGENT | 紧急消息 | 红色 |

## 📱 前端集成建议

### 1. 消息中心页面

```vue
<template>
  <div class="notification-center">
    <!-- 未读数量徽章 -->
    <el-badge :value="unreadCount" class="item">
      <el-button icon="el-icon-bell" @click="showNotifications"></el-button>
    </el-badge>
    
    <!-- 消息列表 -->
    <el-drawer title="消息中心" :visible.sync="drawerVisible">
      <el-tabs v-model="activeTab">
        <el-tab-pane label="未读" name="unread">
          <notification-list :notifications="unreadList" @read="handleRead" />
        </el-tab-pane>
        <el-tab-pane label="全部" name="all">
          <notification-list :notifications="allList" />
        </el-tab-pane>
      </el-tabs>
    </el-drawer>
  </div>
</template>

<script>
export default {
  data() {
    return {
      unreadCount: 0,
      unreadList: [],
      allList: [],
      drawerVisible: false,
      activeTab: 'unread'
    }
  },
  mounted() {
    this.loadUnreadCount();
    // 每30秒刷新一次未读数量
    setInterval(() => {
      this.loadUnreadCount();
    }, 30000);
  },
  methods: {
    async loadUnreadCount() {
      const res = await this.$axios.get(`/notification/unread/count/${this.userId}`);
      if (res.data.code === 0) {
        this.unreadCount = res.data.data.count;
      }
    },
    async showNotifications() {
      this.drawerVisible = true;
      await this.loadUnreadList();
    },
    async loadUnreadList() {
      const res = await this.$axios.get(`/notification/unread/${this.userId}`);
      if (res.data.code === 0) {
        this.unreadList = res.data.data;
      }
    },
    async handleRead(notificationId) {
      await this.$axios.put(`/notification/read/${notificationId}`);
      this.loadUnreadCount();
      this.loadUnreadList();
    }
  }
}
</script>
```

// 定时清理30天前的已读消息
@Scheduled(cron = "0 0 2 * * ?")  // 每天凌晨2点
public void cleanOldNotifications() {

    QueryWrapper<Notification> wrapper = new QueryWrapper<>();
    wrapper.eq("is_read", 1)
