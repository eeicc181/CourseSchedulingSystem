## 📥 数据导出功能

### 导出格式
- 文件类型: CSV
- 编码: UTF-8 with BOM
- 文件名: `教室利用率报表_学期_日期.csv`

### 导出内容
```
教室名称,所属教学楼,容量,利用率(%),已用时长(h),空闲时长(h),当前状态
A栋101,A栋,50,75,26,9,空闲
...
```

### 实现方式
```javascript
// 生成CSV内容
const csvContent = '标题行\n' + 数据行;

// 创建Blob并下载
const blob = new Blob(['\ufeff' + csvContent], { 
  type: 'text/csv;charset=utf-8;' 
});
```
