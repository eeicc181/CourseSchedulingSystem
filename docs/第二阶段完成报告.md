## 💻 技术实现

### 冲突检测算法

#### 1. 教师冲突检测
```java
// 按教师编号+上课时间分组
Map<String, List<CoursePlan>> teacherTimeMap
// 查找同一时间有多个课程的教师
if (plans.size() > 1) {
    // 标记为教师冲突
}
```

#### 2. 教室冲突检测
```java
// 按教室编号+上课时间分组
Map<String, List<CoursePlan>> classroomTimeMap
// 查找同一时间被多个课程占用的教室
if (plans.size() > 1) {
    // 标记为教室冲突
}
```

#### 3. 时间冲突检测
```java
// 按班级编号+上课时间分组
Map<String, List<CoursePlan>> classTimeMap
// 查找同一时间有多个课程的班级
if (plans.size() > 1) {
    // 标记为时间冲突
}
```

## 📝 使用说明

### 1. 启动系统
```bash
# 后端
cd CourseArrange
mvn spring-boot:run

# 前端
cd UI/coursearrange
npm run dev
```

### 2. 访问冲突检测
```
http://localhost:8081/#/conflict-detection
```

### 3. 使用流程
1. 选择学期
2. 点击"开始检测"
3. 查看冲突统计
4. 筛选冲突类型
5. 展开查看详情
6. 点击"建议"查看解决方案

## 🔍 冲突示例

### 教师冲突
```
教师 张老师 在 周一1-2节 有 2 个课程安排
涉及课程：
- 高等数学 | 计算机1班 | A101
- 线性代数 | 计算机2班 | A102

建议：调整其中 1 个课程的上课时间
```

### 教室冲突
```
教室 A101 在 周一3-4节 被 2 个课程占用
涉及课程：
- 数据结构 | 李老师 | 计算机1班
- 算法设计 | 王老师 | 计算机2班

建议：为其中 1 个课程更换教室或调整时间
```

### 时间冲突
```
班级 计算机1班 在 周二1-2节 有 2 个课程
涉及课程：
- 操作系统 | 张老师 | A201
- 计算机网络 | 李老师 | B101

建议：调整其中 1 个课程的上课时间
```

## ⚠️ 注意事项

### 1. 数据要求
- 课程计划表必须有数据
- 教师、教室、班级信息完整
- 上课时间格式统一

### 2. 冲突级别
- **HIGH（高）**: 教师冲突、教室冲突
- **MEDIUM（中）**: 时间冲突
- **LOW（低）**: 暂未使用

### 3. 已知限制
- 不支持跨学期检测
- 不支持自动解决冲突
- 不支持冲突历史记录
