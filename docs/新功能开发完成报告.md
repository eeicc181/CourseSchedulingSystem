```java
// 实体类
```

#### API 接口（9个）
1. `GET /notification/unread/{receiverId}` - 获取未读消息
2. `GET /notification/list/{receiverId}` - 获取消息列表（分页）
3. `GET /notification/unread/count/{receiverId}` - 获取未读数量
4. `PUT /notification/read/{notificationId}` - 标记已读
5. `PUT /notification/read/all/{receiverId}` - 批量标记已读
6. `DELETE /notification/delete/{notificationId}` - 删除消息
7. `POST /notification/send/system` - 发送系统通知
8. `GET /notification/detail/{notificationId}` - 获取详情
9. `GET /notification/stats/{receiverId}` - 获取统计


#### API 接口（7个）
1. `GET /analysis/overview` - 系统概览
2. `GET /analysis/schedule/statistics` - 排课统计
3. `GET /analysis/classroom/utilization` - 教室利用率
4. `GET /analysis/teacher/workload` - 教师工作量
5. `GET /analysis/course/time-distribution` - 时间分布
6. `GET /analysis/conflict/statistics` - 冲突统计
7. `GET /analysis/dashboard` - 数据大屏（汇总）

#### 分析维度

**1. 系统概览**
- 教师/学生/教室/课程总数
- 排课完成数/任务总数
- 完成率统计

**2. 排课统计**
- 按星期分布（周一到周日）
- 按时间段分布（1-2节到7-8节）

**3. 教室利用率**
- 每个教室使用次数
- 利用率百分比
- 高/中/低利用率分类

**4. 教师工作量**
- 每个教师周课时数
- 工作负荷等级（高/中/低/无）
- 负荷分布统计

**5. 课程时间分布**
- 7天 x 4时段热力图
- 课程密度可视化

**6. 冲突统计**
- 教师/教室/班级冲突数
- 冲突率计算

## 🎯 使用指南

### 1. 消息通知系统

#### 初始化数据库
```bash
mysql -u root -p db_course_arrangement < database/notification.sql
```

#### 发送通知
```java
@Autowired
private NotificationService notificationService;

// 发送系统通知
notificationService.sendSystemNotification(
    "系统维护通知",
    "系统将于今晚22:00进行维护",
    NotificationConstants.ReceiverType.ALL,
    null
);
```

#### 查询未读消息
```bash
GET http://localhost:8080/notification/unread/T001
```
