- ✅ 字符串非空验证

**使用示例**:
```java

// 验证成绩

    return ServerResponse.ofError("成绩必须在0-100之间");
}
```

**优势**:

## 🚀 使用建议

### 1. 数据验证最佳实践

**在 Controller 层验证**:
```java
@PostMapping("/input")
public ServerResponse inputScore(@RequestBody Score score) {
    // 验证学号
    if (!ValidationUtil.isValidStudentNo(score.getStudentNo())) {
        return ServerResponse.ofError("学号格式错误");
    }
    
    // 验证成绩
    if (!ValidationUtil.isValidScore(score.getUsualScore())) {
        return ServerResponse.ofError("平时成绩格式错误");
    }
    
    // 业务逻辑
    return scoreService.inputScore(score);
}
```

### 2. 错误处理最佳实践

**统一异常处理**:
```java
try {
    // 业务逻辑
    boolean result = service.doSomething();
    return result ? ServerResponse.ofSuccess() : ServerResponse.ofError("操作失败");
} catch (Exception e) {
    log.error("操作失败", e);
    return ServerResponse.ofError("操作失败：" + e.getMessage());
}
```
