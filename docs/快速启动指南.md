# 🚀 教室利用率分析系统 - 快速启动指南

## 📋 系统概述

**教室利用率分析系统**是一个基于真实数据库的课程排课管理系统的分析模块，提供：
- 📊 实时教室利用率统计
- 📈 多维度数据可视化
- 🔍 灵活的筛选和搜索
- 📥 数据导出功能
- 📱 完整的响应式支持

---

## ⚡ 快速启动

### 1. 启动后端服务

#### 方式一：使用IDE
```
1. 打开 IDEA/Eclipse
2. 导入 CourseArrange 项目
3. 运行 Application 主类
```

#### 方式二：使用Maven命令
```bash
cd CourseArrange
mvn spring-boot:run
```

**验证后端启动成功**:
```
访问: http://localhost:8080
看到页面或JSON响应即表示成功
```

---

### 2. 启动前端服务

```bash
cd UI/coursearrange
npm run dev
```

**验证前端启动成功**:
```
浏览器自动打开: http://localhost:8081
或手动访问该地址
```

---

### 3. 访问教室利用率分析页面

```
直接访问: http://localhost:8081/#/classroom-utilization
```

或通过系统菜单导航进入

## 🎯 核心功能使用

### 1. 查看统计数据
- **总教室数**: 显示系统中所有教室数量
- **空闲教室**: 当前未被占用的教室数
- **平均利用率**: 所有教室的平均使用率
- **高峰时段**: 使用率最高的时间段

### 2. 筛选和搜索
```
学期筛选: 选择特定学期查看数据
教学楼筛选: 按教学楼过滤教室
关键词搜索: 输入教室名称快速查找
```

### 3. 查看图表
- **利用率统计图**: 按教学楼展示利用率（可切换柱状图/折线图）
- **状态分布图**: 饼图显示空闲/使用中/维护中的教室分布
- **时段热力图**: 7天×5时段的使用热度
- **周趋势图**: 一周内利用率变化趋势

### 4. 查看详情
```
点击教室列表中的"详情"按钮
查看教室的完整信息和利用率详情
```

### 5. 查看课表
```
点击教室列表中的"课表"按钮
查看该教室本周的课程安排
```

### 6. 导出数据
```
点击"导出报表"按钮
下载CSV格式的教室利用率数据
```

## 🗄️ 数据库要求

### 必需的表
```sql
1. tb_classroom - 教室信息表
2. tb_course_plan - 课程计划表
3. tb_teachbuild_info - 教学楼信息表
4. tb_course_info - 课程信息表
```

### 数据准备
确保数据库中有：
- ✅ 至少几条教室记录
- ✅ 一些课程计划记录
- ✅ 教学楼信息记录

## 📊 API端点

### 1. 获取所有教室利用率
```
GET /classroom/utilization/all
参数: semester (可选)
```

### 2. 按教学楼获取
```
GET /classroom/utilization/building/{teachbuildNo}
参数: semester (可选)
```

### 3. 获取统计摘要
```
GET /classroom/utilization/summary
参数: semester (可选)
```

## 🐛 常见问题

### 1. 后端启动失败
**问题**: 端口被占用
```bash
解决: 
1. 检查8080端口是否被占用
2. 修改application.yml中的端口配置
```

**问题**: 数据库连接失败
```bash
解决:
1. 检查MySQL是否启动
2. 验证数据库用户名密码
3. 确认数据库名称正确
```

### 2. 前端启动失败
**问题**: 依赖安装失败
```bash
解决:
npm cache clean --force
npm install
```

**问题**: 端口被占用
```bash
解决:
修改 config/index.js 中的 port 配置
```

### 3. 页面无数据
**问题**: API调用失败
```bash
解决:
1. 打开浏览器控制台查看错误
2. 检查后端是否正常运行
3. 验证API地址是否正确
```

**问题**: 数据库无数据
```bash
解决:
1. 检查数据库表是否有数据
2. 系统会自动切换到模拟数据
```

## 🚀 一键启动脚本

### Windows
```batch
@echo off
echo 启动教室利用率分析系统...

echo 1. 启动后端...
cd CourseArrange
start cmd /k "mvn spring-boot:run"

echo 2. 等待后端启动...
timeout /t 10

echo 3. 启动前端...
cd UI\coursearrange
start cmd /k "npm run dev"

echo 4. 打开浏览器...
timeout /t 5
start http://localhost:8081/#/classroom-utilization

echo 启动完成！
```

```bash
#!/bin/bash
echo "启动教室利用率分析系统..."

cd UI/coursearrange
```
