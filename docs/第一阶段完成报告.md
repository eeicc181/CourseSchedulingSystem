## 📝 API文档

### 教室利用率API

#### 获取所有教室利用率
```
GET /classroom/utilization/all?semester=2023-2024-1
```

**响应示例**:
```json
{
  "code": 200,
  "data": [{
    "id": 1,
    "classroomNo": "A101",
    "classroomName": "A栋101",
    "utilizationRate": 75.5,
    "weeklyHours": 16,
    "status": "occupied"
  }]
}
```

#### 获取统计摘要
```
GET /classroom/utilization/summary?semester=2023-2024-1
```

### 教师工作量API

#### 获取所有教师工作量
```
GET /teacher/workload/all?semester=2023-2024-1
```

**响应示例**:
```json
{
  "code": 200,
  "data": [{
    "teacherNo": "T001",
    "teacherName": "张老师",
    "weeklyHours": 16,
    "workloadLevel": "normal",
    "courses": [...]
  }]
}
```

#### 获取统计摘要
```
GET /teacher/workload/summary?semester=2023-2024-1
```
