### 日志级别

| 级别 | 说明 | 使用场景 |
|------|------|---------|
| **TRACE** | 最详细 | 调试时使用 |

| **INFO** | 一般信息 | 生产环境 |
| **WARN** | 警告信息 | 潜在问题 |

## 📋 使用指南

### 在代码中使用日志

#### 1. 引入 Logger

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

@Service
public class UserService {
    private static final Logger logger = LoggerFactory.getLogger(UserService.class);
    
    // ...
}
```

#### 2. 记录不同级别的日志

```java
// DEBUG - 调试信息
logger.debug("查询用户列表，参数：page={}, size={}", page, size);

// INFO - 一般信息
logger.info("用户登录成功，用户名：{}", username);

// WARN - 警告信息
logger.warn("密码错误次数过多，用户名：{}", username);

// ERROR - 错误信息
logger.error("用户注册失败，错误信息：{}", e.getMessage(), e);
```

#### 3. 业务日志示例

```java
@Service
public class CoursePlanService {
    private static final Logger logger = LoggerFactory.getLogger(CoursePlanService.class);
    
    public ServerResponse createCoursePlan(CoursePlan plan) {
        logger.info("开始创建课程计划，课程：{}，教师：{}", plan.getCourseNo(), plan.getTeacherNo());
        
        try {
            // 业务逻辑
            coursePlanDao.insert(plan);
            
            logger.info("课程计划创建成功，ID：{}", plan.getId());
            return ServerResponse.ofSuccess("创建成功");
        } catch (Exception e) {
            logger.error("课程计划创建失败，错误：{}", e.getMessage(), e);
            return ServerResponse.ofError("创建失败");
        }
    }
}
```

## 🎯 日志最佳实践

### 1. 日志内容规范

**✅ 好的日志**:
```java
logger.info("用户登录成功，用户ID：{}，IP：{}", userId, ip);
logger.error("数据库连接失败，错误：{}", e.getMessage(), e);
logger.warn("缓存未命中，key：{}", cacheKey);
```

**❌ 不好的日志**:
```java
logger.info("success");  // 信息不明确
logger.error(e.getMessage());  // 缺少堆栈信息
logger.debug("user=" + user);  // 字符串拼接，性能差
```

### 2. 日志级别选择

```java
// DEBUG - 详细的调试信息
logger.debug("方法参数：param1={}, param2={}", param1, param2);

// INFO - 重要的业务流程
logger.info("订单创建成功，订单号：{}", orderNo);

// WARN - 不影响运行的警告
logger.warn("配置文件缺少可选项：{}", configKey);

// ERROR - 需要立即处理的错误
logger.error("支付失败，订单号：{}，错误：{}", orderNo, e.getMessage(), e);
```

### 3. 性能优化

**使用占位符，避免字符串拼接**:
```java
// ✅ 推荐
logger.debug("用户信息：{}", user);

// ❌ 不推荐
logger.debug("用户信息：" + user.toString());
```

**使用条件判断**:
```java
// 对于复杂的日志内容
if (logger.isDebugEnabled()) {
    logger.debug("详细信息：{}", expensiveOperation());
}
```

## 🔍 日志查看与分析

### 1. 实时查看日志

```bash
# 查看所有日志
tail -f logs/coursearrange-all.log

# 查看错误日志
tail -f logs/coursearrange-error.log

# 查看最近 100 行
tail -n 100 logs/coursearrange-all.log
```

### 2. 搜索日志

```bash
# 搜索关键词
grep "用户登录" logs/coursearrange-all.log

# 搜索错误
grep "ERROR" logs/coursearrange-all.log

# 搜索特定时间段
grep "2024-12-06 13:" logs/coursearrange-all.log
```

### 3. 统计分析

```bash
# 统计错误数量
grep -c "ERROR" logs/coursearrange-error.log

# 统计各级别日志数量
grep -o "ERROR\|WARN\|INFO\|DEBUG" logs/coursearrange-all.log | sort | uniq -c

# 查找最频繁的错误
grep "ERROR" logs/coursearrange-error.log | cut -d' ' -f6- | sort | uniq -c | sort -rn | head -10
```

## 🚀 进阶配置

### 1. 异步日志

```xml
<appender name="ASYNC_FILE" class="ch.qos.logback.classic.AsyncAppender">
    <appender-ref ref="FILE_ALL"/>
    <queueSize>512</queueSize>
    <discardingThreshold>0</discardingThreshold>
</appender>
```

### 2. 日志压缩

```xml
<rollingPolicy class="ch.qos.logback.core.rolling.TimeBasedRollingPolicy">
    <fileNamePattern>${LOG_PATH}/${APP_NAME}-%d{yyyy-MM-dd}.%i.log.gz</fileNamePattern>
</rollingPolicy>
```

### 3. 邮件告警

```xml
<appender name="EMAIL" class="ch.qos.logback.classic.net.SMTPAppender">
    <smtpHost>smtp.example.com</smtpHost>
    <to>admin@example.com</to>
    <from>system@example.com</from>
    <subject>系统错误告警</subject>
    <layout class="ch.qos.logback.classic.PatternLayout">
        <pattern>%d{yyyy-MM-dd HH:mm:ss} [%thread] %-5level %logger{50} - %msg%n</pattern>
    </layout>
    <filter class="ch.qos.logback.classic.filter.ThresholdFilter">
        <level>ERROR</level>
    </filter>
</appender>
```
