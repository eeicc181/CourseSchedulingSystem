## 🚀 快速开始

### 启动系统
```bash
# 1. 启动后端（8080端口）
cd CourseArrange
mvn spring-boot:run

# 2. 启动前端（8081端口）
cd UI/coursearrange
npm run dev

# 3. 浏览器访问
http://localhost:8081
```

### 访问新功能
登录系统后，在菜单中找到：
- 数据分析 → 教室利用率分析
- 数据分析 → 教师工作量统计

## 📊 功能演示

### 教室利用率分析
1. **查看统计** - 总教室数、空闲教室、平均利用率等
2. **筛选数据** - 选择学期、教学楼、搜索教室

2. **筛选数据** - 选择学期、搜索教师姓名

4. **查看详情** - 点击"详情"查看教师完整工作量信息
5. **查看课程** - 点击"课程"查看该教师的授课列表
6. **导出数据** - 点击"导出报表"下载CSV文件

## 📝 数据说明

### 教室利用率计算
```
利用率 = (已使用时段 / 总时段) × 100%
总时段 = 7天 × 5节课 = 35个时段
```

### 工作负荷等级
- **轻负荷**: < 8课时/周（绿色）
- **正常**: 8-16课时/周（蓝色）
- **重负荷**: 16-20课时/周（橙色）
- **超负荷**: > 20课时/周（红色）

## 🐛 常见问题

### 1. 页面无数据显示
**原因**: 数据库中没有数据或后端未启动
**解决**: 
- 检查后端服务是否运行
- 检查数据库是否有数据
- 系统会自动切换到模拟数据

### 2. 图表不显示
**原因**: ECharts未正确加载
**解决**: 
- 刷新页面
- 检查浏览器控制台错误
- 确认网络连接正常

### 3. 导出失败
**原因**: 浏览器阻止下载
**解决**: 
- 允许浏览器下载
- 检查是否有数据
- 尝试更换浏览器
