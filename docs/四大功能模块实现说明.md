#### 页面路径

#### 核心功能
- 📊 教师工作量列表
- 📈 工作量分布图表
- 🔍 按学期/部门筛选
- 📥 导出功能

## 2️⃣ 课程冲突检测

### 功能说明
检测排课中的时间冲突、教室冲突、教师冲突

### 后端实现

#### 文件结构
```
ConflictDetectionVO.java - 冲突检测响应实体
ConflictDetectionController.java - 控制器
```

#### API端点
```
GET /conflict/detect?semester=2023-2024-1
GET /conflict/teacher/{teacherNo}
GET /conflict/classroom/{classroomNo}
```

#### 冲突类型
1. **时间冲突** - 同一教师同一时间多个课程
2. **教室冲突** - 同一教室同一时间多个课程
3. **学生冲突** - 同一班级同一时间多个课程

### 前端实现

#### 页面路径
`src/views/analysis/ConflictDetection.vue`

#### 核心功能
- 🔍 冲突列表展示
- 📊 冲突统计图表
- 🎯 冲突详情查看
- ⚠️ 冲突级别标识

---

## 3️⃣ 智能排课建议

### 功能说明
基于规则的智能排课建议系统

### 后端实现

#### 文件结构
```
ScheduleSuggestionVO.java - 排课建议响应实体
ScheduleSuggestionController.java - 控制器
```

#### API端点
```
POST /schedule/suggest
GET /schedule/optimize/{semester}
GET /schedule/available-slots
```

#### 建议规则
1. **教师优先级** - 考虑教师职称和经验
2. **时间优先级** - 避开早晚时段
3. **教室匹配** - 根据人数匹配教室
4. **分散原则** - 同一课程分散在不同天

### 前端实现

#### 页面路径
`src/views/analysis/ScheduleSuggestion.vue`

#### 核心功能
- 🎯 自动排课建议
- 📊 可用时段展示
- 🔄 排课优化方案
- ✅ 一键应用建议

## 4️⃣ 历史数据对比分析

### 功能说明
对比不同学期的数据变化趋势

### 后端实现

#### 文件结构
```
HistoricalComparisonVO.java - 历史对比响应实体
HistoricalComparisonController.java - 控制器
```

#### API端点
```
GET /historical/compare?semesters=2023-2024-1,2023-2024-2
GET /historical/trend/{metric}
GET /historical/summary
```

#### 对比维度
1. **教室利用率** - 学期间对比
2. **教师工作量** - 学期间对比
3. **课程数量** - 学期间对比
4. **学生人数** - 学期间对比

### 前端实现

#### 页面路径
`src/views/analysis/HistoricalComparison.vue`

#### 核心功能
- 📊 多学期对比图表
- 📈 趋势分析
- 📉 变化率统计
- 📥 对比报告导出
