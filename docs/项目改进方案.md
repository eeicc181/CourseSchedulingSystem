## 1. 系统架构优化

### 1.1 引入缓存机制

**问题描述**：
- 频繁查询数据库导致响应速度慢
- 排课结果、课表数据等重复查询较多
- 系统并发能力有限

**改进方案**：

#### 1.1.1 Redis 缓存集成

```xml
<!-- pom.xml -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-redis</artifactId>
</dependency>
```

```yaml
# application.yml
spring:
  redis:
    host: localhost
    port: 6379
    database: 0
    timeout: 3000ms
    lettuce:
      pool:
        max-active: 8
        max-wait: -1ms
        max-idle: 8
        min-idle: 0
```

**缓存策略**：
- **课表数据**: 缓存时间 1 小时，更新时清除
- **教师/学生信息**: 缓存时间 30 分钟
- **教室列表**: 缓存时间 1 天
- **统计数据**: 缓存时间 5 分钟

**预期效果**：
- 响应速度提升 60-80%
- 数据库负载降低 50%
- 支持更高并发访问

```sql
-- 学生表索引

CREATE INDEX idx_student_no ON tb_student(student_no);

-- 课表查询复合索引
CREATE INDEX idx_schedule_query ON tb_course_plan(semester, grade_no, class_no, class_time);
```

**预期效果**：
- 查询速度提升 70-90%
- 复杂查询响应时间从秒级降至毫秒级

#### 2.1.2 SQL 优化

**问题 SQL**：
```sql
-- 原始查询（N+1 问题）
SELECT * FROM tb_course_plan WHERE semester = '2024-1';
-- 然后循环查询教师、课程、教室信息
```

**优化后**：
```sql
-- 使用 JOIN 一次性查询
SELECT 
    cp.*,
    t.realname as teacher_name,
    c.course_name,
    cr.classroom_name
FROM tb_course_plan cp
LEFT JOIN tb_teacher t ON cp.teacher_no = t.teacher_no
LEFT JOIN tb_course c ON cp.course_no = c.course_no
LEFT JOIN tb_classroom cr ON cp.classroom_no = cr.classroom_no
WHERE cp.semester = '2024-1';
```

**优化建议**：
- 使用 MyBatis-Plus 的 `@TableField(exist = false)` 避免无用字段查询
- 分页查询使用 `limit` 而非全表扫描
- 避免 `SELECT *`，只查询需要的字段

**实现方案**：
```java
@Service
public class ClassroomRecommendService {
    
    public List<Classroom> recommendClassroom(CourseTask task) {
        // 1. 根据班级人数筛选容量合适的教室
        // 2. 优先推荐同一教学楼的教室（减少学生走动）
        // 3. 考虑教室设备（多媒体、实验室等）
        // 4. 考虑教室使用频率（避免过度使用）
        
        return classrooms.stream()
            .filter(c -> c.getCapacity() >= task.getStudentCount())
            .sorted(Comparator
                .comparing(c -> calculateScore(c, task))
                .reversed())
            .limit(5)
            .collect(Collectors.toList());
    }
}
```

#### 3.1.2 教师工作量平衡

**功能描述**：
自动分析教师工作量，提醒管理员调整课程分配。

**实现方案**：
```java
@Service
public class TeacherWorkloadService {
    
    public WorkloadReport analyzeWorkload(String semester) {
        Map<String, Integer> workloadMap = new HashMap<>();
        
        // 统计每位教师的课时数
        List<CoursePlan> plans = coursePlanDao.selectBySemester(semester);
        plans.forEach(plan -> {
            String teacherNo = plan.getTeacherNo();
            workloadMap.merge(teacherNo, plan.getCourseHours(), Integer::sum);
        });
        
        // 计算平均值和标准差
        double avg = workloadMap.values().stream()
            .mapToInt(Integer::intValue)
            .average()
            .orElse(0);
        
        // 标记工作量过高或过低的教师
        return new WorkloadReport(workloadMap, avg);
    }
}
```

```java
@Service
public class ClassroomAnalysisService {
    
    public ClassroomUtilizationReport analyze(String semester) {
        // 统计每个教室的使用情况
        Map<String, Integer> usageMap = new HashMap<>();
        
        List<CoursePlan> plans = coursePlanDao.selectBySemester(semester);
        plans.forEach(plan -> {
            String classroomNo = plan.getClassroomNo();
            usageMap.merge(classroomNo, 1, Integer::sum);
        });
        
        // 计算利用率（假设每周5天，每天10节课）
        int totalSlots = 5 * 10;
        Map<String, Double> utilizationMap = usageMap.entrySet().stream()
            .collect(Collectors.toMap(
                Map.Entry::getKey,
                e -> (e.getValue() * 100.0) / totalSlots
            ));
        
        return new ClassroomUtilizationReport(utilizationMap);
    }
}
```

```java
@Service
public class PasswordService {
    
    private final BCryptPasswordEncoder encoder = new BCryptPasswordEncoder();
    
    // 加密密码
    public String encodePassword(String rawPassword) {
        return encoder.encode(rawPassword);
    }
    
    // 验证密码
    public boolean matches(String rawPassword, String encodedPassword) {
```

### 5.2 接口安全

#### 5.2.1 请求频率限制

```java
@Component
public class RateLimitInterceptor implements HandlerInterceptor {
    
    private final Map<String, AtomicInteger> requestCounts = new ConcurrentHashMap<>();
    
    @Override
    public boolean preHandle(HttpServletRequest request, 
                            HttpServletResponse response, 
                            Object handler) {
        String ip = request.getRemoteAddr();
        String key = ip + ":" + System.currentTimeMillis() / 60000; // 每分钟
        
        AtomicInteger count = requestCounts.computeIfAbsent(key, k -> new AtomicInteger(0));
        
        if (count.incrementAndGet() > 100) { // 每分钟最多100次请求
            response.setStatus(429); // Too Many Requests
            return false;
        }
        
        return true;
    }
}
```

```java
        return userDao.selectList(new QueryWrapper<User>()
            .apply("username like '%" + keyword + "%'")); // SQL注入风险
    }
    
    // ✅ 安全的方式
    public List<User> searchUserSafe(String keyword) {
        return userDao.selectList(new QueryWrapper<User>()
            .like("username", keyword)); // 使用预编译
    }
}
```
