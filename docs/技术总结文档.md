## 三、遗传算法实现详解

### 3.1 算法原理

遗传算法通过模拟生物进化过程求解优化问题，主要包括：
- **选择（Selection）**: 选择适应度高的个体
- **交叉（Crossover）**: 个体间基因交换
- **变异（Mutation）**: 随机改变基因，增加多样性

### 3.2 排课算法核心流程

```java
@Transactional
@Override
public ServerResponse classScheduling(String semester) {
    // 1. 根据学期获得开课任务
    List<ClassTask> classTaskList = classTaskDao.selectList(wrapper);
    
    // 2. 将开课任务编码成染色体（固定时间与不固定时间）
    List<Map<String, List<String>>> geneList = coding(classTaskList);
    
    // 3. 给初始基因编码随机分配时间，得到同班上课时间不冲突的编码
    List<String> resultGeneList = codingTime(geneList);
    
    // 4. 将分配好时间的基因编码以班级分类成为个体
    Map<String, List<String>> individualMap = transformIndividual(resultGeneList);
    
    // 5. 遗传进化
    individualMap = geneticEvolution(individualMap);
    
    // 6. 分配教室并做教室冲突检测
    List<String> resultList = finalResult(individualMap);
    
    // 7. 解码最终的染色体获取基因信息
    List<CoursePlan> coursePlanList = decoding(resultList);
    
    // 8. 写入课程计划表
    coursePlanDao.deleteAllPlan();
    for (CoursePlan coursePlan : coursePlanList) {
        coursePlanDao.insertCoursePlan(...);
    }
    
    return ServerResponse.ofSuccess("排课成功！");
}
```

### 3.3 算法关键步骤

#### 步骤1: 编码（Coding）
- 将课程任务的各项信息编码成染色体
- 区分固定时间和不固定时间的课程
- 每个基因代表一门课程的完整信息

#### 步骤2: 时间分配（CodingTime）
- 为初始基因随机分配上课时间
- 确保同一班级的课程时间不冲突
- 生成初始可行解

#### 步骤3: 个体转换（TransformIndividual）
- 将基因按班级分类
- 形成以班级为单位的个体
- 每个个体代表一个班级的完整课表

#### 步骤4: 遗传进化（GeneticEvolution）
- 计算个体适应度
- 执行选择、交叉、变异操作
- 迭代优化，寻找最优解

#### 步骤5: 教室分配（FinalResult）
- 为排好时间的课程分配教室
- 检测教室使用冲突
- 确保教室容量满足班级人数

#### 步骤6: 解码（Decoding）
- 将染色体解码为课程计划
- 提取课程、教师、教室、时间等信息
- 生成最终课表

## 七、技术难点与解决方案

### 7.1 排课冲突检测

**难点**: 如何高效检测时间冲突、教室冲突、教师冲突

**解决方案**:
- 使用染色体编码表示课程信息
- 在遗传进化过程中实时检测冲突
- 使用适应度函数惩罚冲突方案
- 分阶段处理：先解决时间冲突，再解决教室冲突

### 7.2 算法收敛性

**难点**: 遗传算法可能陷入局部最优，无法找到全局最优解

**解决方案**:
- 设置合理的种群规模
- 调整交叉率和变异率
- 引入精英保留策略
- 设置最大迭代次数防止无限循环

### 7.3 性能优化

**难点**: 大规模数据排课时性能下降

**解决方案**:
- 数据库查询优化（索引、分页）
- 算法并行化处理
- 缓存常用数据
- 异步处理排课任务

### 7.4 数据一致性

**难点**: 多用户并发操作时的数据一致性

**解决方案**:
- 使用事务管理（@Transactional）
- 乐观锁/悲观锁机制
- 数据库约束（主键、外键、唯一索引）
